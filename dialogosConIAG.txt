2) Cuales son los principales metodos de la libreria timeit en python pra medir tiempos:

Respuesta IA:

La librería timeit de Python sirve para medir tiempos de ejecución de fragmentos pequeños de código de forma precisa. Estos son sus métodos principales:

1. timeit.timeit()

Ejecuta un fragmento de código N veces y devuelve el tiempo total en segundos.

python
import timeit

tiempo = timeit.timeit(stmt="sum(range(100))", number=10000)
print(tiempo)  # ej: 0.234

Parámetros clave:

stmt: el código a medir (string o callable)
setup: código que se ejecuta una vez antes (imports, variables)
number: cuántas veces se repite (por defecto 1.000.000)
globals: para pasar el contexto actual, útil con globals=globals()
2. timeit.repeat()

Igual que timeit() pero repite la medición varias veces y devuelve una lista de tiempos. Es más confiable porque permite quedarse con el mínimo (menos afectado por ruido del sistema).

python
tiempos = timeit.repeat(stmt="sum(range(100))", number=1000, repeat=5)
print(min(tiempos))

3) Como funcionan los metodos sorted() o list.sort() en python, diferencias claves.

Respuesta IA:

list.sort() ordena la lista in-place (modifica la original) y devuelve None. Solo funciona con listas.

sorted() devuelve una nueva lista ordenada sin modificar el original. Funciona con cualquier iterable (listas, tuplas, strings, diccionarios, sets, generadores).
python
# list.sort() - modifica la lista original
numeros = [3, 1, 4, 1, 5, 9, 2, 6]
numeros.sort()
print(numeros)  # [1, 1, 2, 3, 4, 5, 6, 9]

# sorted() - devuelve una nueva lista
numeros = [3, 1, 4, 1, 5, 9, 2, 6]
ordenados = sorted(numeros)
print(ordenados)  # [1, 1, 2, 3, 4, 5, 6, 9]
print(numeros)    # [3, 1, 4, 1, 5, 9, 2, 6] (sin cambios)

Parámetros

Ambos aceptan los mismos dos parámetros opcionales:

reverse: booleano para orden descendente.

python
sorted([3, 1, 4, 1, 5], reverse=True)  # [5, 4, 3, 1, 1]

key: función que se aplica a cada elemento para decidir el criterio de orden.

python
palabras = ["banana", "kiwi", "manzana", "pera"]
sorted(palabras, key=len)  # ['kiwi', 'pera', 'banana', 'manzana']

# Ordenar tuplas por el segundo elemento
datos = [("Ana", 30), ("Luis", 25), ("Eva", 28)]
sorted(datos, key=lambda x: x[1])
# [('Luis', 25), ('Eva', 28), ('Ana', 30)]

El algoritmo: Timsort

Por debajo, ambos usan Timsort, un algoritmo híbrido creado por Tim Peters en 2002 que combina merge sort e insertion sort. Aprovecha secuencias ya ordenadas ("runs") que aparecen naturalmente en los datos reales.

Características:

Estable: elementos con la misma clave mantienen su orden relativo original.
Complejidad: O(n log n) en el peor caso, O(n) en el mejor (datos casi ordenados).
Muy eficiente con datos parciales o previamente ordenados.
Ejemplo de estabilidad
python
estudiantes = [("Ana", "B"), ("Luis", "A"), ("Eva", "B"), ("Juan", "A")]
sorted(estudiantes, key=lambda x: x[1])
# [('Luis', 'A'), ('Juan', 'A'), ('Ana', 'B'), ('Eva', 'B')]
# Luis va antes que Juan porque estaba antes en la lista original
¿Cuál usar?

Usa list.sort() cuando no necesites conservar el orden original y trabajes con una lista (ahorra memoria). Usa sorted() cuando quieras preservar el original, o cuando trabajes con otro iterable como una tupla o un diccionario.

5) Adopta el rol de profesional de informatica; y enseña las bases de encriptacion RSA:

Respuesta:

Bases de Encriptación RSA

¡Hola! Soy profesional de informática y hoy vamos a desglosar uno de los algoritmos más importantes de la criptografía moderna: RSA. Lo explicaré paso a paso, desde los fundamentos matemáticos hasta un ejemplo práctico con números pequeños.

1. ¿Qué es RSA?

RSA (Rivest-Shamir-Adleman, 1977) es un algoritmo de criptografía asimétrica o de clave pública. Esto significa que utiliza dos claves distintas pero matemáticamente relacionadas:

Clave pública: se comparte abiertamente. Sirve para cifrar mensajes.
Clave privada: se mantiene en secreto. Sirve para descifrar mensajes.

A diferencia de la criptografía simétrica (como AES), donde ambas partes comparten la misma clave, en RSA cualquiera puede cifrar un mensaje con tu clave pública, pero solo tú (con tu clave privada) puedes descifrarlo.

2. Fundamentos matemáticos

RSA se basa en tres conceptos clave de la teoría de números:

a) Números primos

Un número primo solo es divisible por 1 y por sí mismo (2, 3, 5, 7, 11, 13...).

b) Función φ de Euler (phi)

Para un número n = p * q (donde p y q son primos):

φ(n) = (p - 1) * (q - 1)
c) Aritmética modular

La operación a mod n devuelve el resto de dividir a entre n.
Ejemplo: 17 mod 5 = 2.

d) El problema de la factorización

La seguridad de RSA se basa en que factorizar un número muy grande (producto de dos primos enormes) es computacionalmente inviable con tecnología actual.

3. Generación de claves (paso a paso)
Elegir dos primos grandes: p y q.
Calcular n: n = p * q → este será el módulo de ambas claves.
Calcular φ(n): φ(n) = (p - 1) * (q - 1).
Elegir e (exponente público): un entero tal que 1 < e < φ(n) y gcd(e, φ(n)) = 1 (coprimos). Comúnmente se usa e = 65537.
Calcular d (exponente privado): el inverso modular de e módulo φ(n):
   d * e ≡ 1 (mod φ(n))

Resultado:

Clave pública = (e, n)
Clave privada = (d, n)
4. Cifrado y descifrado

Sea M el mensaje (convertido a número, M < n):

Cifrar: C = M^e mod n
Descifrar: M = C^d mod n
5. Ejemplo práctico con números pequeños

Vamos a cifrar el número M = 7.

Paso 1 — Elegir primos:

p = 11,  q = 13

Paso 2 — Calcular n:

n = 11 * 13 = 143

Paso 3 — Calcular φ(n):

φ(n) = (11 - 1) * (13 - 1) = 10 * 12 = 120

Paso 4 — Elegir e:

e = 7  (es coprimo con 120)

Paso 5 — Calcular d (inverso modular de 7 mod 120):

d = 103   (porque 7 * 103 = 721 = 6*120 + 1 ≡ 1 mod 120)

Claves:

Pública: (e=7, n=143)
Privada: (d=103, n=143)

Cifrar M = 7:

C = 7^7 mod 143 = 823543 mod 143 = 123

Descifrar C = 123:

M = 123^103 mod 143 = 7  ✓
